    Image prompts

    I am about to ask you to generate seven different poses for a book mascot. Please use a consistent drawing style for all seven images.

    Each prompt below is fully self-contained (includes the complete base character description) so it can be used independently. Full identity details live in character-sheet.md.

    1. Neutral / Default Pose¶

    Please generate a new pose for Nova the Chambered Nautilus.

    A modern flat vector illustration of Nova the Chambered Nautilus, a friendly pedagogical mascot for a "Migrating from MkDocs to Zensical" documentation textbook. Nova has a deep indigo-blue shell (#3F51B5) with pale cream growth-line stripes tracing the spiral chambers, and subtle geometric spiral linework on the shell surface. Nova's eyes and the rim of the shell's aperture (opening) are warm orange (#FF6F00). Nova wears a tiny brass compass on a thin cord resting against the front of the shell. Nova has a warm, curious, closed-mouth smile with large friendly eyes. The character is small and compact, suitable for icon-sized display. Style: modern flat vector illustration, clean lines, transparent background with alpha channel, suitable for embedding in educational content. No text in image.

    Nova stands in a relaxed, neutral pose facing the viewer directly, tentacles resting naturally with no specific gesture. The pose is balanced and unassuming — suitable as a general-purpose or default illustration. Filename: neutral.png

    Please generate a new RGBA PNG image now with a fully transparent alpha-channel background. The background MUST be fully transparent with an alpha channel. DO NOT use a white, black, or checkered background.
