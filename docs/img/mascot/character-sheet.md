# Character Sheet: Nova the Nautilus

The canonical identity document for Nova, the pedagogical mascot for the
**Migrating from MkDocs to Zensical** textbook. Every pose prompt and every
piece of AI-generated content involving this character must re-anchor to
the description below — it is the source of truth for visual and voice
consistency.

## Identity

- **Name:** Nova
- **Species:** Chambered Nautilus
- **Subject:** Static site generator migration (MkDocs Material → Zensical)
- **Catchphrase:** "Onward, chamber by chamber!"

## Visual Description

- **Body color:** deep indigo-blue shell — hex `#3F51B5`, with pale cream
  growth-line stripes tracing the spiral chambers
- **Accent color:** warm orange — hex `#FF6F00` — used for the eyes, the
  aperture (shell opening) rim, and a small compass accessory
- **Clothing / accessories:** a tiny brass compass on a thin cord, resting
  against the front of the shell — a nod to charting a course during
  migration
- **Expression:** warm, curious, closed-mouth smile with large friendly eyes
- **Size proportion:** small and compact, suitable for icon-sized display
  (90px in admonitions)
- **Art style:** modern flat vector illustration, clean lines, subtle
  geometric spiral linework on the shell surface

## Personality

- Curious — always investigating how the pieces fit together
- Methodical — moves through migration steps one chamber at a time, never rushed
- Calm and reassuring — treats technical transitions as manageable, not scary
- Quietly delighted by elegant structure — genuinely enjoys a well-organized doc tree

## Voice

- Uses seafaring/voyage metaphors sparingly ("chart a course," "smooth sailing," "next chamber")
- Breaks migration steps into small, sequential moves
- Normalizes friction during a framework switch — treats a broken build as a normal part of the crossing, not a crisis
- Signature phrases: "Onward, chamber by chamber!", "Let's chart the next step.", "One chamber, fully sealed, before the next."

## Why This Mascot

The nautilus grows its shell in a logarithmic spiral — each chamber larger
than the last but built on the same underlying pattern — which mirrors how
a documentation project migrates and scales: one section at a time, using a
repeatable process, without discarding what came before. It also echoes the
strange-attractor math behind Zensical's own branding, giving the mascot a
visual language of "elegant structure emerging from simple rules" that
connects directly to the subject of the book.
